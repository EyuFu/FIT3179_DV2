# The Open-Air Gym

How Australians use parks, paths and beaches to exercise, and how that compares with the gym.
FIT3179 Data Visualisation 2 (Monash University), October 2026.

* `index.html`: the page
* `css/style.css`: layout and typography
* `js/*.vg.json`: one Vega-Lite specification per chart (12 charts)
* `js/main.js`: embeds the charts with vega-embed
* `data/`: cleaned data files used by the charts (sources are listed in the page footer)
* `sketch/sketch.pdf`: the hand-drawn sketch
